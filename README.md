# 📊 Plotting 2D Graphs in Python

A simple guide and repository demonstrating how to create various 2D plots and graphs using Python libraries.

## 🚀 Features
* **Line Plots**: Visualize continuous data trends.
* **Bar Charts**: Compare categorical data easily.
* **Scatter Plots**: Identify correlations between variables.
* **Customization**: Learn how to adjust colors, labels, legends, and grid lines.
